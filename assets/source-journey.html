Two routes

Same bar. Same badge. Different start line.

The journey is more technical than functional by default. Technical people route through the FTE badge. Functional / advisory people likely route through a Value Architect or Trust Architect variant — same competency map, reframed entry points. Names aren't official yet.

Frontier Transformation Engineer

Technical / developer route

You already code. The route sharpens AI-native build fluency, agent frameworks, RPI discipline, and the Azure stack — then forces the facilitation and commercial half that technical people usually skip.

→ Anchor: FTE badge · build-heavy competency weighting
🧭

Value Architect / Trust Architect

Functional / advisory route · provisional

You're strong on discovery, stakeholders and business framing. The route adds the model mechanics, prompt & context fluency, and enough hands-on build to be credible in the room — without becoming a full-stack developer.

→ Anchor: HVE literacy + value framing · facilitation-heavy weighting

The proof point · Redmond

Three days. Three FDE pods. Three working AI builds.

The Microsoft FDE Hackathon in Redmond put Microsoft, Accenture and Avanade in one room around real problems with a clear build bias. It validated the market is ready for a formal FDE operating model — and exposed the structure we need to scale it.

Don't let it die at the demo.

The hackathon is the proof point. The real opportunity is turning what happened in Redmond into a repeatable FDE operating model — framed across three layers. The hackathon sits exactly at their intersection: it activated supply, created proof for demand, and exposed the support structures we need to scale.
